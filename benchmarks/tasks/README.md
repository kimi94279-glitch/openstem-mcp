# 과제 비교용 과제 틀

openstem을 붙인 호스트와 비교 대상 서비스를 같은 과제로 비교하는 사람 평가의 과제 모음이다. 절차(조건 맞추기, 블라인드 채점, 루브릭, 결과 형식)는 [docs/benchmarks.md](../../docs/benchmarks.md#2-과제-비교사람-평가)에 있다.

```
<id>/prompt.md     두 쪽에 그대로 보낼 지시문
<id>/rubric.md     항목별 0~4 기준과 반드시 있어야 할 요소(채점 전에 고정)
<id>/inputs/       첨부 파일. 직접 만든 것만 둔다
results/*.jsonl    점수만(결과물·다른 서비스의 출력은 넣지 않는다)
```

지금은 영역마다 과제를 채우기 전의 예시 3개만 있다. 새 과제는 이 셋을 복사해 만든다.
