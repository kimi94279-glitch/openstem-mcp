# 7주차 노트: 이상기체와 열역학 제1법칙

(이 노트는 벤치마크용으로 직접 쓴 것이다.)

## 이상기체 상태방정식

- PV = nRT. P: 압력(Pa), V: 부피(m³), n: 몰수(mol), T: 절대온도(K).
- 기체 상수 R = 8.314 J/(mol·K). 볼츠만 상수로 쓰면 PV = NkT, k = 1.381 × 10⁻²³ J/K, N = nN_A.
- 섭씨는 반드시 켈빈으로 바꾼다: T(K) = t(°C) + 273.15.

## 내부 에너지

- 단원자 이상기체: U = (3/2)nRT. 이원자(상온): U = (5/2)nRT.
- 이상기체의 U는 온도만의 함수다. 따라서 ΔU = nC_VΔT는 **어떤 과정이든** 성립한다.
- 몰비열: 단원자 C_V = (3/2)R, C_P = (5/2)R. 이원자 C_V = (5/2)R, C_P = (7/2)R. 항상 C_P − C_V = R, γ = C_P / C_V.

## 열역학 제1법칙(이 강의의 부호 규약)

- **ΔU = Q − W**. Q: 계가 **받은** 열, W: 계가 **한** 일.
- 부피가 늘면(팽창) 계가 일을 하므로 W > 0. W = ∫P dV.

## 네 가지 과정

- 등적(V 일정): W = 0, Q = nC_VΔT.
- 등압(P 일정): W = PΔV = nRΔT, Q = nC_PΔT.
- 등온(T 일정): ΔU = 0, W = nRT ln(V₂/V₁), Q = W.
- 단열(Q = 0): W = −ΔU = −nC_VΔT. PV^γ = 일정, TV^(γ−1) = 일정. W = (P₁V₁ − P₂V₂)/(γ − 1).

## 자주 하는 실수

- 등온 과정에서 "온도가 안 변하니 열도 0"이라고 쓰는 것(Q = W ≠ 0).
- 교과서마다 W의 부호 규약이 다르다(ΔU = Q + W로 쓰는 책은 W가 계가 **받은** 일).
