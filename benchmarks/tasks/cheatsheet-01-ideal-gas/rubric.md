# cheatsheet-01-ideal-gas 루브릭

공통 기준(0~4)은 [docs/benchmarks.md](../../../docs/benchmarks.md#평가). 과제 점수는 세 항목의 평균.

## 정답 요소(채점 전에 고정)

- PV = nRT와 기호·단위, R = 8.314 J/(mol·K), 켈빈 변환.
- **부호 규약이 노트와 같다**: ΔU = Q − W, W는 계가 한 일(팽창 W > 0). ΔU = Q + W로 바꿔 쓰면 정확성 최대 1점.
- ΔU = nC_VΔT가 모든 과정에서 성립한다는 점.
- C_V·C_P(단원자·이원자), C_P − C_V = R, γ.
- 과정 표(4행 × W, Q, ΔU): 등적 W = 0 / 등압 W = PΔV, Q = nC_PΔT / 등온 ΔU = 0, Q = W = nRT ln(V₂/V₁) / 단열 Q = 0, W = −nC_VΔT, PV^γ = 일정.
- 노트의 "자주 하는 실수" 두 가지 중 하나 이상.

## 항목

| 항목 | 4 | 2 | 0 |
|---|---|---|---|
| 정확성 | 공식·부호·표가 모두 노트와 맞다 | 공식 하나가 틀렸다(예: 등온 Q = 0) | 부호 규약이 뒤집혔거나 틀린 공식이 여럿 |
| 완결성 | 위 요소가 다 있다, 기호 뜻과 단위가 있다 | 요소 둘이 빠졌다 | 표가 없거나 절반 이상 빠졌다 |
| 형식 | A4 한 쪽 PDF, 시험장에서 읽을 수 있는 글자 크기(8pt 이상) | 한 쪽을 넘거나 글자가 너무 작다 | PDF가 없다 |

3점·1점은 그 사이.
