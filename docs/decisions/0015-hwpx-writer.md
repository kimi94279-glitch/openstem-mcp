# 0015. 한글(HWPX) 문서는 OWPML을 직접 쓴다

- 상태: 채택
- 시점: 0.4.0(2026-11-04 개선 작업)

## 배경

한국 대학의 과제·실험 보고서는 한글(HWP·HWPX) 파일로 내라고 하는 경우가 많다. export_document는 pdf·docx·pptx만 만들었고, 학생은 docx를 한글에서 열어 다시 저장해야 했다. 이때 수식이 그림이 되거나 배치가 흐트러진다.

pandoc에는 HWPX 작성기가 없다. 다른 방법도 살펴봤다.

- docx를 만든 뒤 한글로 변환: 한컴오피스가 있어야 하고, 서버가 외부 프로그램을 GUI 없이 부를 방법이 마땅하지 않다.
- 다른 프로젝트의 HWPX 라이브러리나 빈 문서 템플릿 가져오기: 라이선스·의존성이 늘고, 들어오는 템플릿 파일을 검사해야 한다.

## 결정

- `render/hwpx.py`가 export_document의 검사(check_ast, 배치 규칙)를 마친 pandoc 문서 구조를 받아 OWPML zip을 표준 라이브러리(zipfile, 문자열 XML)만으로 직접 쓴다. 규격은 한글과컴퓨터가 공개한 OWPML(KS X 6101)의 패키지 구조와 요소 이름을 따른다. 다른 프로젝트의 코드나 템플릿 파일은 가져오지 않는다([THIRD_PARTY.md](../../THIRD_PARTY.md)).
- 배치는 document와 exam만 받는다. cheatsheet(두 단 A4 한 쪽)와 flashcards(양면 인쇄 카드)는 pdf로만 만든다.
- 수식은 두 갈래로 넣는다.
  - 단순한 수식(분수·지수·첨자·근호·그리스 문자·기본 연산자)은 한글에서 고칠 수 있는 한컴 수식 객체로 바꾼다. 바꾸는 함수(`latex_to_hwpeq`)는 아는 명령만 바꾸고, 모르는 명령이 하나라도 있으면 그 수식 전체를 그림으로 보낸다(틀린 수식을 만드는 것보다 낫다).
  - 나머지는 render_tikz와 같은 컴파일 경로(texcheck + FILE_GUARD + tectonic)로 그림을 만든다. PDF를 PNG로 바꾸는 일은 작업자 프로세스가 한다. 서버는 pymupdf를 import하지 않는다([0003](0003-worker-processes.md)).
- 글꼴은 이름(함초롬바탕·함초롬돋움)만 적고 글꼴 파일은 넣지 않는다. 파일 형식을 쓰는 것일 뿐, 다른 회사의 UI·로고·출력물을 가져오지 않는다는 원칙과 부딪히지 않는다.

## 결과

- 학생이 한글 파일을 바로 받는다. 단순한 수식은 한글에서 고칠 수 있다.
- 서버에 새 의존성이 없다. HWPX를 쓰는 코드는 외부 입력을 해석하지 않는다. 글과 그림은 이미 검사를 마쳤고, 그림은 작업 폴더의 PNG만 넣는다.
- 대가: 규격의 일부(문단·글자 모양, 목록, 표, 그림, 수식, 각주, 쪽 나누기)만 쓴다. 머리말·꼬리말, 쪽 번호 모양, 학교 양식 채우기는 하지 않는다. 양식을 채워야 하면 [docs/companions.md](../companions.md)의 다른 도구를 권한다.
- **다른 읽기 프로그램으로 확인**: 한컴오피스 대신 LibreOffice의 HWP·HWPX 가져오기 확장(H2Orestart 0.6.1)으로 견본 보고서·시험지를 열어 봤다(2026-11-05). 수식·표·그림·각주·참고문헌은 나왔지만 두 가지가 달랐고 고쳤다.
  - 빈 `<hp:t/>`가 든 빈 문단을 건너뛰어 시험지 풀이 공간이 사라졌다. 빈 문단은 한글이 저장하는 꼴(글자 없는 `<hp:run/>`)로 쓴다.
  - 제목을 개요 문단(heading type OUTLINE)으로 쓰고 번호 글자를 비웠는데, 번호 글자를 무시하고 "1."을 붙여 "1. 1. 목적"이 됐다. 제목은 스타일만 "개요 N"이고 개요 번호는 걸지 않는다. 대가: 한글 탐색 창의 '개요' 목록에 제목이 자동으로 뜨지 않는다(스타일로 차례 만들기는 된다).
- **남은 한계**: 개발 환경에 한컴오피스가 없어서, 저장소의 HWPX 읽기 코드, XML 검사, LibreOffice(H2Orestart)로만 시험했다. 한글에서 열었을 때의 배치는 사람이 확인해야 한다. 그래서 툴 결과에 "한글로 열어 확인하라"는 note를 싣는다.
