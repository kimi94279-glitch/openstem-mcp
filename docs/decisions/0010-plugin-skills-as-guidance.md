# 0010. Claude 플러그인의 스킬은 사용 지침만 담고, 범용 기능은 다른 스킬에 맡긴다

- 상태: 채택
- 시점: 0.3.2

## 배경

툴 설명만으로는 LLM이 "언제, 어떤 순서로" 툴을 쓸지 충분히 알지 못한다. MCP 프롬프트는 사용자가 메뉴에서 골라야 하고, 호스트에 따라 아예 보이지 않는다. Claude는 스킬(SKILL.md)을 요청에 맞춰 스스로 불러온다. 한편 슬라이드 디자인·워드 서식 같은 범용 기능은 이미 잘 만든 다른 스킬이 있다.

## 결정

- `claude-plugin/`에 서버(`.mcp.json`, 고정 버전 `uvx openstem-mcp==<버전>`)와 스킬 6개(풀이 검산, 그림, 시험 대비, 실험 보고서, 발표·문서, 학교 LMS)를 함께 묶는다.
- 스킬은 사용 지침이다. openstem은 그림·수식·검산·한국 자료(HWP·LMS)를 맡고, 레이아웃·디자인은 세션에 다른 문서·발표 스킬이 있으면 그쪽에 맡긴다(`slides-and-documents`).
- 스킬 본문은 영어(LLM이 읽음), description에는 한국어 요청 표현을 넣는다.
- 플러그인 버전과 서버 버전을 함께 올린다(`tests/test_plugin.py`가 확인).

## 결과

- 툴 이름이나 인자를 바꾸면 스킬과 프롬프트도 함께 고쳐야 한다. 같은 작업 순서가 프롬프트(`src/openstem/prompts/`)와 스킬 두 곳에 있다.
- 로컬 MCP 서버는 Claude Code와 내 PC의 Cowork에서만 뜨고, claude.ai 채팅에서는 스킬만 실린다.
