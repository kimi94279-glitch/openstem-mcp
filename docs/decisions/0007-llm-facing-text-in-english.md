# 0007. LLM이 읽는 글은 영어, 사람이 보는 글은 한국어로 쓴다

- 상태: 채택
- 시점: M6(0.3.0)

## 배경

툴 설명·인자 설명·서버 안내문은 대화마다 호스트 LLM의 문맥에 실린다. 한국어는 같은 내용을 영어보다 2~3배 많은 토큰으로 쓴다. 한편 사용자는 대부분 한국어로 대화하고, 호스트 앱 메뉴와 설치 화면은 사람이 직접 본다.

## 결정

- **영어**(짧게): 툴·인자 설명, 서버 INSTRUCTIONS, 에러·힌트·노트·경고, 결과 속 설명 값, 프롬프트 본문, 스킬 본문. LLM이 사용자의 언어로 옮겨 전한다.
- **한국어**: 코드 주석, 사람이 직접 보는 것(툴·프롬프트·리소스 title, 프롬프트 설명·인자 설명 = 호스트 앱 메뉴, CLI 출력, .mcpb 설치 화면), 학생이 받는 문서 안의 글(그림·표 이름, 시험지 학번·이름 칸, 카드 앞면·뒷면, 그래프 범례 "맞춤:"·"3σ 밖"), 한글 처리용 상수·정규식, 기본 자료 폴더 이름 "자료".
- 시험지 해설 제목은 `# 정답과 해설`이 기본이고 `# Answers`·`# Solutions`도 받는다.
- 프롬프트마다 "사용자의 언어로 답하고 문서도 그 언어로" 줄을 넣는다. 스킬 description에는 한국어 요청 표현을 넣어 트리거되게 한다.

## 결과

- 대화마다 실리는 문맥이 줄었다.
- 툴 설명에는 JSON 입력 예시(`{"`)와 `On failure:` 줄이 꼭 있어야 한다(`tests/test_server.py`가 확인).
