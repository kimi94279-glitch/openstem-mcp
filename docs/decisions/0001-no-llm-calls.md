# 0001. 서버는 LLM을 부르지 않는다

- 상태: 채택
- 시점: M1(처음부터)

## 배경

이공계 학습용 유료 AI 앱이 파는 핵심 기능은 풀이 검산, 학술 그림, 문서 내보내기다. 학생 상당수는 이미 Claude·ChatGPT 같은 AI를 쓰고 있다. 서버가 따로 LLM을 부르면 누군가 그 비용을 내야 하고, 그러면 무료로 유지할 수 없다.

## 결정

풀이·판단·글쓰기는 사용자의 LLM(MCP 호스트)이 한다. 서버는 그리기(TeX·matplotlib·RDKit), 계산(sympy·pint·numpy), 변환(pandoc·pymupdf)처럼 결정적인 일만 한다. API 키를 받지 않는다.

## 결과

- 운영비가 0이다. 작성자는 서버를 운영하지 않고 데이터를 받지 않는다([PRIVACY.md](../../PRIVACY.md)).
- 결과의 질은 호스트 LLM에 달려 있다. 그래서 툴은 LLM이 결과를 스스로 확인하고 고칠 수 있게 미리보기와 짧은 에러를 돌려준다([0002](0002-tool-result-contract.md)).
- 호스트가 하는 일(이미지 인식, 웹 검색, 대화 기록)은 서버가 다시 만들지 않는다.
